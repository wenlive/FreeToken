## 数值问题：进展与边界

HF 对拍使用同一官方 Q8 权重的官方数学参考，llama.cpp 使用同一文件，作为独立误差标尺。
以下来自五提示的固定历史对拍，而非比较各自生成后的不同历史。

| 场景 | native/HF top-1 一致 | native/HF 平均 KL | llama/HF 平均 KL | native tile 扰动平均 KL |
| --- | ---: | ---: | ---: | ---: |
| Causal | 159/160，99.4% | 0.00413 | 0.00344 | 0.00335 |
| 块预览 W8/W16/W32 | 736/840，87.6% | 0.03094 | 0.03079 | 0.02206 |

这支持正常算术差异经路由、量化与离散选择放大的解释，但不是完整通过：按此前建议的
逐位置 `1.2 × max(llama-HF, native-noise)` 标尺，仍有超界位置。没有调高阈值以通过。
相对 logit L2 不等于任务质量下降百分比；top-1 分歧也不直接等于答案错误。

关键定位结果：

- 五个短提示关闭 sparse admission 后，40 层捕获张量逐位相同，已排除它在这些样本中的影响。
- 第 0 层 mixer 输入与 HF 相同，输出 L2 为 0.36–0.46%，MLP 输出为 1.08–1.97%。
  相同实际输入上的 GDN 输出误差约 0.42–0.50%。定位到了最早差异，尚未证明具体算子写错。
- 最终 hidden-state 对 HF 的 L2 为 5.49–8.32%，native 自身 tile 扰动为 4.49–9.80%，
  说明整模型会明显放大小的实现差别。
- split-KV 单算子对 FP32 的 L2 约 0.165–0.174%，但整模型仍有超出扰动标尺的案例，
  因此保持默认关闭。

最新 JSON W32 同轨迹检查记录真实首块的 14 轮输入，三方逐轮读取同样的部分固定块。
240 个仍为 mask 的位置上，native/HF KL 为 0.03711，llama/HF 为 0.03342，
native 与 tile/eager 对照为 0.03882。HF 在 13/14 轮选择的提交数量与 native 相同，
另一轮为 4 对 3；llama 和扰动对照的数量在 14 轮都相同。但选择的具体位置只有
9/14 轮与 HF 相同，后续轨迹仍可能分岔。这进一步支持放大效应，尚不足以关闭 B1。
参考沿 native 的轨迹评估，这些数量不是 HF 自主去噪速度；该扰动对照还使用了 eager 预览。

实际输出检查中，15 例有 5 例逐 ID 相同。计数题完全相同；天空和中文题主要是措辞；
Python W16 有格式与 docstring 差异；JSON 有紧凑/缩进格式以及选书差异。JSON 原先
2.46–2.67 对 4.00 tokens/preview 同时包含不同输出格式与历史，不能直接视为同一答案的
算法效率差距。Python、JSON、中文样本存在 64-token 截断，因此未完成完整任务质量验收。
另外两项自然长上下文任务的 18 次运行均给出正确最终数字，但这不是通用质量证明。

结论是 causal 对齐较好，块预览对数值扰动更敏感；正常范围的解释有实测支持，仍保留未解释
项。没有证据足以宣称普遍严重质量退化，也没有证据足以宣称 HF 完整质量等价。

## 验收与已有性能水平

最新 serving 源码 `a5190a5`：112 种尾长 graph 审计、W32 → 742-token prefill → ss16
生命周期、预热状态完整性通过；Flash-Next MTP 开/关及 Qwen3.6 与 main 的 9 项输出比较
逐 ID 一致；79 项集中 GPU 测试通过。目录整理后又运行选定回归，509 passed、
147 skipped、47 subtests passed。缺少 Gemma4 Q4_0 本地权重的实模型回归未标为通过。

以下性能实测绑定 `8767ada`（serving `5df3410`），不是新 HEAD 的重新测量。
RTX 5070 Ti 16GB，官方 Q8，单请求、checkpoint 惩罚、host embedding、auto .9，
每格一次预热加一次正式样本，输出上限 256。

| 模式 | 短输入 decode tok/s | 4K 输入 decode tok/s |
| --- | ---: | ---: |
| 自回归 causal | 90.86 | 86.87 |
| 自投机 W8 | 92.72 | 79.23 |
| 自投机 W16 | 89.86 | 86.44 |
| 块扩散 W16 | 58.71 | 51.29 |
| 块扩散 W32 | 48.53 | 36.02 |

decode 排除首个可见输出 burst 和终止 EOS；各模式输出长度/内容可能不同。这是小样本快照，
不是多任务平均或速度提升证明。后来的 128 → 256 阈值改动不改变表中 36/4096 输入的路径。
此前逐项 ABAB 的收益、TTFT、端到端和前向数据均见完整验收记录，不再扩大测量。

## 留给下一轮的明确事项

1. B1 的残余数值/进度差异仍未知；B3 默认关闭；需要完整输出质量样本后才能进一步放宽判断。

   IQ4_XS 没有分组 MMQ 性能保障，不应拿社区 IQ4_XS 的速度代表官方 Q8。
3. 热专家、预览 pin/prefetch、自适应模式及新的多请求计数布局，均未合入，等人工 review 后再定。
4. 大型 logits/状态二进制留在本机，远端归档包含路径与 SHA256；文本证据、失败尝试、命令和
   source identity 均保留。不能把程序正常退出等同于数值验收通过。
